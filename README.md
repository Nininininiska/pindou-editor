# 拼豆图纸编辑器

这是一个单文件、可离线使用的 Mard 221 拼豆编辑器。色板内置 221 个 Mard 色号，全部逻辑和样式都写在 `index.html` 里。

用任意浏览器打开本仓库根目录的 `index.html` 即可使用。不需要联网，也不需要安装依赖或启动服务器。

## 怎么打开

1. 克隆或下载本仓库。
2. 双击 `index.html`，或把该文件拖进浏览器窗口。

## 主要功能

- **绘制**：画笔、橡皮、取色，支持撤销和重做，可调整画布尺寸。
- **色板**：Mard 221 色号，可按色号或十六进制颜色搜索，并统计用豆数量。
- **图片转拼豆**：上传图片，按像素块匹配最接近的豆色，一键生成图纸。
- **导出 PNG**：把当前图纸导出为 PNG 图片。
